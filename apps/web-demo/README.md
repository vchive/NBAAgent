# 种花 Agent Web Demo

这是一个零依赖的中文花卉种植与养护前端（纯 HTML/CSS/JavaScript）。页面支持流式回答、
会话隔离、停止生成、重试、证据状态和额度/服务提示。默认首屏只展示种花品牌与园艺问题，
不会加载或注入历史赛事数据。

## 连接方式

FastAPI 可同源托管本目录。聊天使用 `POST /api/v1/chat/stream`，请求携带同一浏览器标签页内
稳定的 `session_id`；点击“新对话”后才生成新的会话标识。SSE 客户端收到
`message.completed` 或 `run.error` 后立即释放连接，若上游没有发送终止事件则会在超时后
恢复输入框并展示可重试提示。

页面只渲染应用拥有的公开提示，不展示上游名称、端点、账单信息、原始搜索摘要或内部运行时
标识。智能回答或在线资料额度不足时，界面会明确说明能力受限，并保留仍然可用的本地知识
回答。

本地开发可从仓库根目录启动 API：

```bash
python3 -m pip install -e '.[dev]'
uvicorn apps.api.src.main:app --host 127.0.0.1 --port 8000
```

也可以在 `4173` 端口静态预览页面。仅用于前端开发时，可在加载脚本前显式设置
`window.COURTSIDE_RUNTIME_MODE = "demo"`，启用内置的低风险花卉知识回答；公开部署不会在
网络故障时悄悄用演示内容替代服务回答。

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory apps/web-demo
```

若 API 不同源，可在脚本加载前设置 `window.COURTSIDE_API_BASE`。不要把密钥、认证凭据或
第三方接口地址写入浏览器代码。

## 主要交互

- 快速问题覆盖选花、浇水、黄叶排查、季节施肥和宠物误食。
- 全智能模式是会话级开关；服务端仍负责安全短路、资料核验和输出清洗。
- 回答可包含文本、事实卡片、表格、谨慎分析、澄清问题和安全提示。
- 危险农药混用、未知植物误食及人/宠物暴露应优先显示安全行动和专业求助方向。
- “新对话”会清空动态消息和植物上下文，避免跨会话串线。
- 网络、认证、超时、搜索额度或智能回答额度异常都以用户可理解的状态呈现，并在可重试时
  提供重试按钮。

`api-client.js` 仍保留旧的全局兼容名，同时提供 `window.FlowerApi` 别名；两者使用相同、受控
的同步/SSE 契约，不向页面提供任意 URL 抓取能力。
