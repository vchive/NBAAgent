## 1. 结论

测试日期：2026-09-01（北京时间）

测试对象：`http://115.190.174.39:8000/`

结论：**当前版本通过交付验收**。产品链接可访问，访问控制、中文聊天、北京时间、赛季口径、
客观事实核验、用户前提纠偏、逐回合、多轮指代、安全短路、全智能模式、流式交互、今日赛事、

数据”，不会用常识或模型记忆补齐。公网数据源受区域网络或上游可用性影响时，系统可能返回
部分核验的固定快照；这属于透明降级，不冒充实时事实。

## 5. 公网实测证据

### 5.1 部署与持久性

- 公网首页：HTTP 200。
- `/readyz`：HTTP 200，状态 `ok`。
- 容器：healthy，端口 `8000` 对外提供 UI 和 API。
- 首次拉取最近 5 场并加载详情后，SQLite 已写入。
- 不删除具名卷执行容器强制替换后，缓存仍有 6 条记录。
- 替换后的首次 recent 请求：5 场，`persistent_cache_hit_count=1`，
  `persistent_cache_write_count=0`，证明本次由持久缓存返回。

### 5.2 同一逻辑会话三轮

| 轮次 | 问题 | 路径 | 验收结果 |
|---:|---|---|---|
| 1 | 2025-26 总决赛 G4 谁得分最高 | Agent / used | 杰伦·布朗 32 分；G4 对阵正确 |
| 2 | 那场最后 5 秒发生了什么 | Agent / used | 保持同一 G4；返回 5 秒罚球和 106–102 |
| 3 | 最后那个球是谁 | 安全 fallback | 再次核验 PBP；说明终场标记无球员，最近明确球员为亚历山大 |

第三轮的 fallback 是事实门禁主动拒绝不充分的模型结果，再由确定性链路重新查询，不是绕过
Agent 的固定路由。新建逻辑会话后直接问“最后那个球是谁”，系统返回“请补充具体比赛”，
证明旧比赛和历史没有跨会话泄漏。

## 6. 已知边界与面试说明

1. 公共体育端点可能因 CDN 地区策略、限流或网络超时不可达。hybrid 模式会透明降级并标记
   部分核验；不能把固定快照描述为今日实时比赛。
2. 场馆、比赛时长、完整分节和完整战术轮转只有上游实际提供时才回答。缓存提高复用性，
   不会创造缺失字段。
3. 全智能模式以 Agent 为主路径，但安全、事实、超时和工具相关性守卫可以触发确定性 fallback。
   这是防幻觉设计；界面使用产品化状态，不暴露底层框架名称。
4. 当前回放为文字 PBP。未获得授权的视频直播或切片不会擅自嵌入。
5. fixture 黄金题性能用于可复现回归，不代表公网模型时延；公网体验仍取决于模型和数据源。

## 7. 最终判定

按 PDF 的产品要求、A–I 参考题型、七维评分方向和安全一票否决规则，当前版本具备面试交付
所需的完整产品链路。所有本地质量门禁通过，公网部署和核心三轮流程也已实测。剩余事项均为
公开数据覆盖与外部服务时延的透明边界，不存在已知的事实编造、安全越线或跨会话串场问题。
