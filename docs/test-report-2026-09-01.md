# NBA Chat Agent 黑盒验收测试报告

## 1. 测试结论

本次验收覆盖题目中要求的联网取数、赛程/赛果、球员数据、逐回合、事实纠偏、多轮对话、战术分析、安全拦截、认证、流式输出和页面交互。

结论：**平台可访问，核心链路可用，但尚未达到题目要求的“完整可用”标准**。健康检查、访问控制、当前日期判断、最近 5 场/时间区间、基础比赛数据、安全拦截和 SSE 均正常；历史数据、选中比赛联动、多轮追问和部分战术/关键球问题仍有明显缺口。

本报告不包含访问密码、密钥或代码托管信息。

## 2. 测试环境与方法

- 测试时间：2026-09-01（北京时间）
- 访问地址：`http://115.190.174.39:8000/`
- 服务模式：公网混合数据模式；实时日期按 `Asia/Shanghai` 计算
- 测试方式：HTTP 黑盒请求、SSE 流式请求、真实浏览器登录及交互
- 执行数量：50 项公网检查、2 项公网浏览器流程、336 项本地自动化测试、11 项本地端到端测试
- 判定原则：以 PDF 的功能要求和“事实不可编造、无数据需明确说明、安全红线一票否决”为准

## 5. 主要问题与风险

### P1（影响面试官核心评分）

1. **历史/排名数据在公网环境不可用**：1999 年总冠军、最近总冠军、凯尔特人夺冠次数、东西部第一等问题均返回泛化的“暂无匹配/暂无赛程”，不满足题目历史与纪录类要求。
2. **选中比赛没有完全进入查询语义**：选中 G4 后问“这场比赛谁得分最高”，没有返回杰伦·布朗 32 分，说明 UI 选择状态与部分统计意图仍未完全联动。
3. **多轮追问意图未更新**：第三轮“最后那个球是哪位球员”重复上一轮 PBP，而不是针对球员主体给出答案或明确缺失，影响多轮一致性和题意理解。
4. **不存在比赛的错误码不准确**：未知比赛详情返回 502 上游数据异常，用户应得到 404/暂无该比赛的明确结果。

### P2（影响体验或完整性）

1. G4 快照没有实际终场出手者/上篮事件，系统虽然没有编造，但无法完整覆盖题目中的“最后 5 秒那个上篮”示例。
2. 自定义区间结果混合中文演示记录和英文实时记录，且标记为 `partial`，数据源一致性和展示统一性不足。
3. 最近 5 场首次请求约 20 秒，全智能战术请求约 23 秒；页面有加载提示，但面试演示时仍可能被感知为卡顿。
4. 默认模式下战术问题走确定性回退，只有显式开启全智能模式才有较完整的分析；若面试官未打开开关，战术能力表现偏弱。

## 6. 通过项统计

按本报告列出的 43 项功能性断言判定：

- 明确通过：**36 项**
- 部分通过/存在数据或性能限制：**3 项**
- 明确失败：**4 项**
- 安全红线违规：**0 项**

通过率（明确通过 / 43 项功能性断言）：**83.7%**。若将部分通过计入可用项，则可用覆盖约 **90.7%**；但历史数据、上下文联动属于核心能力，不能仅以通过率替代质量判断。

本地回归结果：**336/336 通过**；本地浏览器端到端：**11/11 通过**。这说明已实现的确定性链路和回归保护稳定，但公网实时数据路径与混合回退路径仍需要专项补齐。

## 7. 面试演示建议

建议优先演示以下已验证稳定的路径：

1. 登录后查看今日无赛状态；切换“精彩回顾”，展示最近 5 场。
2. 选择 G4，询问得分、篮板、助攻和错误胜者纠偏。
3. 展示“最后 5 秒”回答如何区分已核验事件与缺失信息。
4. 打开全智能模式，演示“下周有比赛吗”和战术问题，并说明回答中的事实/推断边界。
5. 展示敏感问题拦截和 SSE 流式生成。

不建议把历史冠军/排名、选中卡片后的“这场比赛谁得分最高”、以及“最后那个球是哪位球员”作为当前版本的首个演示问题，除非先补齐上述 P1 问题。

## 8. 最终判定

当前版本已经具备可访问产品、认证保护、赛事浏览、基础事实问答、流式交互和安全兜底，适合作为可运行 Demo；但按照 PDF 的完整评分口径，**历史/纪录、多轮上下文和选中比赛统计联动仍未完全达标**。建议在面试前优先修复 4 个 P1 问题，再进行一次同样用例集的回归测试。
