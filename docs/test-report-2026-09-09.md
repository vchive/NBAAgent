## 5. 本轮关键缺陷与修复

| 缺陷 | 根因 | 修复与回归 |
|---|---|---|
| 单侧搜索时球员比较退化为澄清 | 恢复器要求网页结果同时覆盖两人 | 在已完成搜索后输出无数字的四维评价框架；成功运行仍标记为全智能 |
| 推荐下钻理解度被误判 | 评测器未把 canonical game 展开为所属双方 | 用声明的比赛成员关系扩展实体校验，同时继续严格校验 game id |
| 已推荐 G2 后又改成 G4 | 事实守卫只校验当前 G4 文案自身，不看上一轮选择 | 增加 active recommendation 一致性门；错误分支恢复为“刚才推荐的就是 G2” |
| 错误“主场险胜”可穿过守卫 | 省略球队名的主客场关系未校验 | 将隐式主/客场胜负与该场实际 winner side 对照 |
| 部分核验比赛丢失推荐上下文 | 只有 evidence=verified 才写候选映射 | 公共结构化 canonical game 即使缺可选字段仍可用于关系和会话绑定；演示数据继续隔离 |
| G5 回顾末尾出现账号名、G4 与 MVP 杂讯 | 智能回答偶发失败后，恢复层把完整同场解释与宽泛搜索摘要强行拼接 | 完整、同场的结构化解释优先；搜索摘要只作内部证据，并加入用户原问题的失败回归 |
| 休赛期赛事下钻显示“最近暂无比赛” | 最近接口先逐日扫描远端，操作预算耗尽后的 partial 空结果又被缓存 | 先查询完整本地索引窗口；partial 空结果不得覆盖最近赛事缓存；缓存 schema 升级并加入重启回归 |
| 搜索或智能额度耗尽被误报为暂无数据 | 故障类型在 fallback、Agent 工具桥和 HTTP/SSE 投影中丢失 | 增加 request-scoped capability notice；有事实继续答并提示，无事实返回 typed failure；共享缓存读写时剥离旧故障 |
| 全智能事实首轮命中 G5、追问却漂移到其他比赛 | 唯一 typed observation 未完整写入 canonical active game，后续只剩宽泛对阵 | 仅允许同轮已核验的唯一比赛写入服务端会话；PBP/元数据追问要求同一 game 的 typed evidence |
| 选中 G5 后自然问得分王只显示比分 | 选中比赛的普通数据意图没有请求已缓存 box score leader | hybrid/full 两条路径都读取该场球员行，回归固定为布伦森 45 分 |
| PBP 显示裸 `90–94`，看似与“尼克斯 94–90 胜”冲突 | PBP 内部使用 home–away 字段顺序，公开文本没有球队标签 | PBP-only 结果重新绑定服务端 canonical game；表格、事件、最后一投与战术事实均输出球队—比分关系 |
| FINAL HUD 仍像未开赛且节次比分为空 | 终场时钟/节次投影错误依赖 live clock 与浅摘要 | FINAL 固定显示 `00:00 · FINAL`，完整 PBP 可推导 Q1–Q4；确实缺失时保留 `—` |

## 7. 产品与隐私检查

- `/readyz` 返回 `status=ok`，公开体验且默认全智能开启。
- 公网 `/api/v1/highlights/recent?limit=5` 返回 5 场且首场为 `hupu:168859`，来源为已核验公开数据；
  无头浏览器登录并点击“赛事下钻”后实际渲染 5 张比赛卡，首卡为 06/14 尼克斯 94–90 马刺。
- 首页、健康接口、公开回答和方案 PDF 均未出现内部运行时品牌。
- 能力提醒仅使用应用自有中文文案；即使上游错误包含供应商、接口地址或计费原文，浏览器也不会展示。
- 永久额度耗尽不提供“重试”按钮；临时限流/超时仍保留可重试语义。
- 演示 fixture 不会在 live/public 请求失败时静默替代公开事实。
- 漫游模式不自动绑定第一场比赛；只有赛事下钻或已核验对话上下文才绑定 canonical game。
- PBP 的主客队字段顺序只保留在内部；公开表格、事件、最后一投和战术依据均带球队标签。
- 加载、网络失败、空数据、取消、重试和会话刷新均有浏览器回归。

## 8. 最终判定与剩余风险

**最终判定：通过核心交付验收。** 当前版本满足 PDF 对中文 NBA 问答、多轮一致性、事实核验、主观分析、
安全短路、Web 交互和已部署产品的核心要求。

剩余风险不是已知事实错误，而是外部服务时延与详情覆盖率：战术和历史搜索题的 P90 仍超过 10 秒，
只有 107/1,386 场具备部分或完整详情，教练与地点组成字段覆盖不足。系统会对缺失字段保持诚实，不将搜索摘要
或模型常识升级为已核验事实。后续优先优化在线搜索/模型延迟，并在可信来源允许时补齐关系字段。
